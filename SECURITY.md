# Security

VERITAS is an active security-audit target — see the "Please Break It" section in README.md and the threat model in docs/SPEC.md.

To report a vulnerability: open a GitHub issue, or email bizzares80@gmail.com for anything you'd rather not disclose publicly first. Verified findings get public credit in the README.

Known limitations are documented in docs/SPEC.md — check there before reporting something already listed.
